# Respuesta de IsThereAnyDeal — 1 de septiembre de 2026

Evidencia recibida por correo por el propietario y aportada mediante captura. Se conserva aquí una transcripción factual sin dirección personal del remitente ni imagen del buzón.

## Resumen de la respuesta

1. El uso privado y no comercial descrito está permitido. La atribución no es obligatoria, aunque sería bienvenida.
2. La API no proporciona los precios reales de Steam para Chile en CLP solicitados.
3. Para las preguntas de cobertura y endpoints, el proveedor remitió a la documentación de la API.
4. Las condiciones requieren utilizar los enlaces proporcionados por la API.

## Evaluación contra el SDD

El permiso de uso queda aclarado favorablemente, pero la fuente no cumple los criterios obligatorios de precio regional `CL`/`CLP`. Además, la obligación de conservar los enlaces proporcionados por la API es incompatible con el requisito actual de usar enlaces directos a Steam. La documentación confirma que no se deben modificar los datos ni retirar etiquetas de sus URLs.

**Decisión:** IsThereAnyDeal fue evaluado y no se integrará con el SDD v1.1 actual. No se registrará una aplicación ni se solicitará una clave. Esta decisión no autoriza el adaptador experimental de Steam ni las fuentes de objetos de Rust.
